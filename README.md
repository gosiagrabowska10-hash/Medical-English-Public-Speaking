# The Medical Speaking Academy

Premium international platform teaching medical public speaking and professional English communication.

- Plan: `docs/IMPLEMENTATION_PLAN.md`
- Design system: `docs/DESIGN_SYSTEM.md` · live at `/design-system`
- Milestone report: `docs/MILESTONE_1_REPORT.md`
- Environment variables: `.env.example`

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
```

Stack: Next.js 16 (App Router, Cache Components) · React 19 · TypeScript · Tailwind CSS v4 · Radix primitives (shadcn-style components) · Supabase, Stripe and OpenAI in later milestones.
